# conditional_efficiency_reweighted

重要な過去 study。保存結果は `output/conditional_efficiency_reweighted/productions/historical/` にあります。

`reproduction.json` の configuration を `run.sh CONFIGURATION --check` で確認し、`run.sh CONFIGURATION --output-base NEW_OUTPUT_BASE` で再実行します。既存ファイルの上書きは拒否します。

[配置](../../docs/layout.md)と[再現手順・検証範囲](../../docs/reproduction.md)を参照してください。解析アルゴリズムは移行前のマクロから変更していません。
