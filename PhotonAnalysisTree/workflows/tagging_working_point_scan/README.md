# Pi0 veto working-point scan

Read one common topology-v11 map production with stored-cluster threshold at or below 0.12 GeV and baseline pi0 E > 0.15 GeV, 0.08 < mass < 0.18 GeV. Recompute all pairs for every saved Region-A candidate, simultaneously evaluating six settings (v2):

| Key | Pi0 partner E | Pi0 mass window |
|---|---|---|
| e0p15_m0p08_0p18 | >0.15 GeV | 0.08–0.18 GeV |
| e0p15_m0p08_0p20 | >0.15 GeV | 0.08–0.20 GeV |
| e0p12_m0p08_0p18 | >0.12 GeV | 0.08–0.18 GeV |
| e0p12_m0p08_0p20 | >0.12 GeV | 0.08–0.20 GeV |
| e0p5_m0p10_0p20 | >0.5 GeV | 0.10–0.20 GeV |
| e0p15_m0p10_0p20 | >0.15 GeV | 0.10–0.20 GeV |

All mass boundaries are strict. Eta veto stays E > 0.5 GeV and 0.45 < mass < 0.65 GeV. The baseline pi0/eta tag flags and final-photon flag must exactly match the saved map for every analyzed candidate. The comparison reference is E > 0.5 GeV, 0.10 < m < 0.20 GeV (mask bit 4); saved-map veto validation still uses bit 0. Prompt and pi0 use the existing exclusive majority composition: prompt flag and dominant fraction >0.5, or pi0 anchor valid and main fraction >0.5, respectively. Eta contribution is computed from signal truth contributors exactly as in photon_candidate_selection. Candidates with more than one majority source enter other/background. All non-prompt Region-A candidates form background. No topology reclassification or map production is performed.

Each candidate fills one raw and weighted prompt/background survival-mask bin; pi0 candidates also fill the pi0 subset histograms. Mask bit w means survival at working point w. This preserves joint outcomes for all six settings, counts multiple qualifying partners only once, and permits exact extra-prompt/background removal counts relative to the E > 0.5 reference. Because mass windows are not nested, recovered prompt is recorded separately; net loss is removed minus recovered. Weights use the full per-sample generator-weight denominator, with map completeness, stitching and settings checks reused from tagging_mass_diagnostic. All seven Jet samples are covered by six ordinary jobs and ten Jet12 shards.

Each partial contains `working_point_scan.root`. Merge verifies exact shard coverage, source settings and histogram axes, preserves every source metadata record, and produces:

- `working_point_scan.root`: prompt/background/pi0 count and weighted 64-bin survival masks (1 GeV candidate ET bins, 0–40 GeV).
- `summary.tsv`: purity, prompt/background survival, weighted before/after yields and additional prompt/background removals, prompt recovery and net-loss fractions, selected pi0 raw counts/weighted yields/fractions, total selected counts/yields for 5–6, 6–8, 8–10, 10–18, 18–30 and 5–30 GeV.
- `RESULTS.md`: Japanese comparison tables generated by `report_scan.py` after baseline validation.
- `purity.pdf`, `prompt_survival.pdf`: six-working-point overlays, focused on ET 5–18 GeV.

Fraction errors use weighted subset covariance at candidate level, as in the existing production; event-level correlations are not estimated. The mask histograms retain overlaps for subsequent correlated comparisons.

## Run

```bash
mkdir -p PhotonAnalysisTree/output/condor/tagging_working_point_scan/v2/reduce
condor_submit PhotonAnalysisTree/workflows/tagging_working_point_scan/submit_reduce_jet_samples.job
condor_submit PhotonAnalysisTree/workflows/tagging_working_point_scan/submit_reduce_jet12_shards.job
```

After both submissions complete:

```bash
PhotonAnalysisTree/workflows/tagging_working_point_scan/run_merge.sh jet \
  PhotonAnalysisTree/output/plots/tagging_working_point_scan/v2/reduce/topology_v11/ClusterE0p12_Pi0Partner0p15_Pi0Window0p08-0p18/jet/partial \
  PhotonAnalysisTree/output/plots/tagging_working_point_scan/v2/topology_v11/ClusterE0p12_Pi0Partner0p15_Pi0Window0p08-0p18/jet
```

Existing ROOT outputs are not overwritten. Event-limited and incomplete-map QA outputs cannot be used for a production merge. The same optional QA parameters as tagging_mass_diagnostic are available on the C++ functions.

## QA

The v2 QA uses two Jet8 maps (64,344 events, 56 Region-A candidates), one reduce partial, and a merge under `output/qa/tagging_working_point_scan/v2/`. Input symlinks live under `output/qa/tagging_working_point_scan/two_maps/maps/jet8/`. `check_scan.py MAP_GLOB MERGED_ROOT` independently recomputes all six pair predicates and exclusive pi0/prompt classification in Python and compares every raw/weighted mask bin and Sumw2 error; this passed. It is intended for small QA inputs only.

For a production v2 output, `check_reference_outputs.py SCAN_ROOT COMPOSITION_BASE PREVIOUS_SCAN_ROOT` compares all raw and weighted prompt/all/pi0 yields and variances before/after veto to the three existing photon compositions (E > 0.5 with 0.10–0.20; E > 0.15 with 0.10–0.20 and 0.08–0.18). It also projects out the new mask bits to compare every bin and variance with the v1 four-setting scan.
